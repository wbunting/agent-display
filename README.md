# agent-display

Rust port of the `agent-display` tool from `wbunting/dotfiles`
(`skills/agent-display/agent-display`, Python): a private headless sway
display, input and agent-only Chromium for agents on the Omarchy host, plus
`agent-display tab` commands to drive a tab over CDP.

The Python version stays the reference and the installed tool
(`~/.local/bin/agent-display`) until this port matches it and is benchmarked.
